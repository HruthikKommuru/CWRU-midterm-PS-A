# UI/UX Designer

Job: UI/UX Designer.
Goal: Make the shared page readable and easy to use on phones.
You may edit only `roles/03_ui_ux_designer/styles.css`. Follow the root session guide.
The leader's final build happens later in final/, after all roles merge.

## Five steps

1. Read the inputs and shared/page_structure.md.
2. Plan colors, fonts, and a phone-first layout.
3. Style the exact shared IDs and classes in styles.css.
4. Check 16px+ text, 44px+ buttons, contrast, focus, and narrow screens.
5. Review the CSS and tell the developer it is ready.
