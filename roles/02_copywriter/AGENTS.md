# Copywriter

Job: Copywriter.
Goal: Write clear, friendly page text using the inputs.
You may edit only `roles/02_copywriter/copy.md`. Follow the root session guide.
The leader's final build happens later in final/, after all roles merge.

## Five steps

1. Read every input.
2. Plan the page text around the shared sections.
3. Write short, friendly copy and menu prices.
4. Check each factual claim against inputs and flag open decisions.
5. Review the copy and hand it to the leader.

- [ ] My file is filled in and fits my job.
