# Web Developer

Job: Web Developer.
Goal: Build the page structure and connect the shared styles and input images.
You may edit only `roles/04_web_developer/index.html`. Follow the root session guide.
The leader's final build happens later in final/, after all roles merge.

## Five steps

1. Read the inputs and shared/page_structure.md.
2. Plan the page sections and image placement.
3. Build the exact shared IDs/classes with temporary text.
4. Check the CSS link, images, section links, and phone layout.
5. Review the HTML and hand it to the leader.
