# Shared page structure (read-only)

Designer and Developer use these exact IDs and classes. Add supporting elements
as needed; do not rename the shared hooks. Do not edit this file.

| Element | ID | Class |
| --- | --- | --- |
| Header | top | site-header |
| Main introduction | hero | hero |
| Menu section | menu | — |
| Each menu entry | — | menu-item |
| Each price | — | menu-price |
| Hours section | hours | — |
| Hours table | — | hours-table |
| About section | about | — |
| Contact section | contact | — |
| Call link | — | btn-call |
| Footer | — | site-footer |

Use one h1, clear section headings, readable image descriptions, and working
section links. The call link uses tel: with the team's chosen input-based phone.
Text must be at least 16px; buttons and call links at least 44px tall/wide.
Start with a single column that fits a 320px-wide phone without side scrolling.

The role page links `../03_ui_ux_designer/styles.css`. From that role page,
input images use `../../inputs/logo.png` or `../../inputs/photos/<filename>`.
In the final build, link `styles.css`. The leader may copy input images into
`final/images/` and use `images/<filename>` so final/ works on its own.
